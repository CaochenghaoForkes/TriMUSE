# 输入模块组织结构

## 目录结构

```text
TriMUSE/
├── main.py                                  # 程序入口, 创建随机数生成器并启动当前任务
├── trimuse/
│   └── input/
│       ├── __init__.py                      # 输入包初始化
│       ├── xml_utils.py                     # XML基础读取, 结构检查和路径解析工具
│       ├── units.py                         # 单位语法解析, 量纲检查和SI单位转换
│       ├── case_config.py                   # 总调度卡配置, 模板和读取器
│       ├── case_examine.py                  # 总调度卡扩展检查预留
│       ├── geometry_mesh_config.py          # 几何与网格卡配置, 模板和读取器
│       ├── geometry_mesh_examine.py         # 几何与网格配置完整性检查
│       └── loader.py                        # 总加载器, 递进加载case及其引用的子卡
└── cases/
    └── test/
        ├── case*.xml                        # 总调度输入卡
        ├── geometry_mesh_stochastic_2d.xml  # 二维随机颗粒几何与网格卡
        └── geometry_mesh_stochastic_3d.xml  # 三维随机颗粒几何与网格卡
```

## 文件职责

### `xml_utils.py`

`XmlUtils` 提供所有XML输入卡共用的底层操作:

- 读取XML文件并检查根节点
- 读取字符串, 整数, 浮点数, 布尔值和节点文本
- 读取唯一直接子节点或多个同名直接子节点
- 检查未知属性和未知直接子节点
- 读取统一格式的 `value` 和 `unit`
- 相对于指定目录解析文件路径
- 写出空输入卡模板

该文件只处理XML通用规则, 不包含具体物理模型逻辑

### `units.py`

`Units` 负责将输入卡中的单位表达转换为Pint可识别的形式:

- 支持相邻方括号表示单位乘积, 如 `[kg][m]/[s]`
- 支持整数幂次, 如 `[m]^2/[s]`
- 处理 `C`, `K`, `F`, `um` 等单位别名
- 检查偏移温度是否被错误用于复合单位
- 检查物理量量纲
- 将长度等物理量转换到规定的SI目标单位

### `case_config.py`

总调度卡对应的主要配置为:

```text
CaseConfig
├── schema_version
├── name
├── random_seed
├── description
├── Output
│   └── directory
├── InputFiles
│   ├── geometry_mesh
│   ├── thermal
│   ├── diffusion
│   ├── mechanics
│   ├── materials
│   ├── coupling
│   └── numerics
└── Execution
    └── target
```

`CaseConfigLoader` 读取 `case.xml`, `CaseConfigTemplate` 在路径为空时生成总调度模板

随机种子和总输出目录属于整个算例, 因此保存在总调度卡中

### `geometry_mesh_config.py`

几何与网格卡对应的主要配置为:

```text
GeometryMeshCard
├── Model
│   └── dimension
├── Geometry
│   ├── source
│   ├── IdealMultilayerSphere
│   │   ├── Center
│   │   └── Layers
│   └── StochasticMultilayerParticle
│       ├── Center
│       ├── OuterSurface
│       └── Layers
└── Mesh
    ├── engine
    ├── Element
    ├── Sizing
    ├── Output
    └── Gmsh
```

主要对象包括:

- `UnitValue`: 保存已读取和转换后的数值及单位
- `GeometryMeshCard`: 保存完整几何与网格配置
- `GeometryMeshCardLoader`: 按XML层次递进读取各节点
- `GeometryMeshCardTemplate`: 生成包含全部节点的空模板

几何卡只描述几何模型, 网格参数和网格文件名, 不保存随机种子和算例总输出目录

### `geometry_mesh_examine.py`

`GeometryMeshExamine` 在配置读取完成后检查跨节点约束:

- 模型维数是否合法
- 几何来源与对应子模型是否一致
- 层名称和边界名称是否为空或重复
- 理想颗粒各层半径是否严格递增
- 随机颗粒的统计量, 圆形度, 球形度和展开参数是否合法
- 单元类型是否与空间维数匹配
- 网格尺寸和区域引用是否合法
- Gmsh算法, 优化器和输出配置是否合法

XML节点是否存在及属性类型主要由读取器检查, `GeometryMeshExamine` 负责配置对象之间的关系检查

### `loader.py`

`CaseLoader` 是当前输入模块的总入口:

- 读取总调度卡
- 相对于总调度卡目录解析子卡路径
- 加载并检查几何与网格卡
- 返回统一的 `LoadedCase`
- 子卡路径为空时生成对应模板

当前仅完整接入几何与网格卡, 其他物理输入卡保留接口

## 输入读取流程

```text
main.py
└── load_case(case_path)
    └── CaseLoader.load
        ├── CaseConfigLoader.load
        │   └── CaseConfig
        ├── 解析geometry_mesh相对路径
        ├── GeometryMeshCardLoader.load
        │   └── GeometryMeshCard
        ├── GeometryMeshExamine.examine
        └── LoadedCase
```

`LoadedCase` 将总调度配置, 几何网格配置及其实际文件路径集中返回给程序入口

## 随机数与输出目录

```text
case.xml中的random seed
└── main.py创建np.random.Generator
    └── 向需要随机取样的模块传递rng

case.xml中的output directory
└── seed_<random_seed>
    └── mesh, thermal, diffusion, mechanics等模块目录
```

当前网格输出目录形式为:

```text
<case所在目录>/<output directory>/seed_<random_seed>/mesh/<mesh file>
```
