# 几何与网格模块组织结构

## 目录结构

```text
TriMUSE/
├── main.py
└── trimuse/
    ├── input/
    │   ├── geometry_mesh_config.py          # 几何与网格配置对象
    │   └── geometry_mesh_examine.py         # 几何与网格配置检查
    └── geometry/
        ├── __init__.py                      # 几何包初始化
        ├── builder.py                       # 几何与网格总调度器
        ├── topology.py                      # 通用几何拓扑数据
        ├── ideal_multilayer_sphere.py       # 理想多层颗粒构造器
        ├── stochastic_multilayer_particle.py # 随机多层颗粒构造器
        └── gmsh_mesh.py                     # 公共Gmsh网格生成流程
```

## 总体调用关系

```text
main.py
└── GeometryMeshBuilder.build(config, output_directory, rng)
    ├── gmsh.initialize
    ├── 根据geometry.source选择构造器
    │   ├── IdealMultilayerSphereBuilder.build
    │   └── StochasticMultilayerParticleBuilder.build
    ├── GeometryTopology
    ├── GmshMesh.generate
    │   ├── 注册物理组
    │   ├── 设置网格尺寸
    │   ├── 设置三维算法
    │   ├── 生成网格
    │   ├── 优化和升阶
    │   ├── 检查材料区域单元
    │   └── 写出MSH及可选VTK
    └── gmsh.finalize
```

## 文件职责

### `builder.py`

`GeometryMeshBuilder` 是几何模块的统一入口:

- 管理Gmsh初始化和释放
- 根据 `geometry.source` 选择具体几何构造器
- 将外部创建的 `rng` 传递给随机几何构造器
- 将几何卡中的相对文件名组合到模块输出目录
- 将 `GeometryTopology` 交给公共网格生成器

该文件不实现具体几何算法或网格算法

### `topology.py`

`GeometryTopology` 保存具体几何构造器与公共网格模块之间的数据:

```text
GeometryTopology
├── dimension                         # 几何最高维数
├── regions                           # 材料名到最高维实体tag列表
└── boundaries                        # 边界名到低一维实体tag列表
```

不同维数下的含义为:

| 维数 | `regions` | `boundaries` |
|---|---|---|
| 1D | 线 | 点 |
| 2D | 面 | 曲线 |
| 3D | 体 | 面 |

具体构造器只需返回统一拓扑, 不负责物理组注册和网格写出

### `ideal_multilayer_sphere.py`

`IdealMultilayerSphereBuilder` 根据维数构造理想同心多层颗粒:

- `_build_radial_line`: 一维分层径向线
- `_build_concentric_circles`: 二维同心圆及环形材料区域
- `_build_concentric_spheres`: 三维同心球及球壳材料区域

每一层按输入卡书写顺序建立材料区域和外边界名称

### `stochastic_multilayer_particle.py`

`StochasticMultilayerParticleBuilder` 根据批次统计和外部 `rng` 构造随机多层颗粒

公共统计步骤:

- 计算条件批次厚度均值
- 计算条件批次厚度标准差
- 在固定外半径约束下抽样本颗粒各层平均尺寸

二维步骤:

```text
目标圆形度
└── 生成外轮廓傅里叶系数
    └── 拆包裹生成各层傅里叶系数
        └── 计算r_l(phi)
            └── 转换为笛卡尔坐标
                └── Gmsh闭合样条和分层平面
```

三维步骤:

```text
目标球形度
└── 生成外表面实球谐系数
    └── 拆包裹生成各层球谐系数
        └── 计算r_l(theta,phi)
            └── 转换为笛卡尔坐标
                └── 三角面片
                    └── 闭合面壳
                        └── 分层材料体
```

三维连续球谐表面当前使用共享点和共享边的平面三角面片进行几何逼近, 每个材料界面对应一组三角面实体

### `gmsh_mesh.py`

`GmshMesh` 提供不同几何来源共用的网格流程:

- 检查当前维数允许的单元类型
- 将 `regions` 和 `boundaries` 注册为命名物理组
- 设置全局最小和最大网格边长
- 通过背景场设置材料区域目标网格尺寸
- 设置三维非结构网格算法
- 生成对应维数的网格
- 优化三维一次网格
- 将网格几何阶次提升到指定阶次
- 检查每个材料区域是否生成最高维单元
- 写出Gmsh MSH文件及可选VTK文件

## 当前支持范围

| 几何来源 | 1D | 2D | 3D |
|---|---|---|---|
| `ideal_multilayer_sphere` | 分层径向线 | 同心圆 | 同心球 |
| `stochastic_multilayer_particle` | 抽样分层径向线 | 傅里叶随机轮廓 | 球谐随机表面 |

当前直接支持的网格单元为:

| 维数 | 单元类型 |
|---|---|
| 1D | `line` |
| 2D | `triangle` |
| 3D | `tetrahedron` |

四边形, 六面体, 棱柱和棱锥已在配置层预留, 但尚未实现对应的结构化或重组流程

## 随机数职责

```text
case.xml
└── random seed
    └── main.py创建rng
        └── GeometryMeshBuilder传递rng
            └── StochasticMultilayerParticleBuilder使用rng
```

几何模块不读取随机种子, 也不自行创建随机数生成器

## 输出路径

几何卡只提供网格文件名, `main.py` 提供本次运行的网格输出目录:

```text
<case目录>/<output目录>/seed_<seed>/mesh/<网格文件名>
```

启用 `write_vtk` 时, VTK文件与MSH文件写入同一目录
