# 二维颗粒恒功率内热源算例

入口为 `cases/source/case.xml`。已完成一次 2 秒计算; 后续自行运行时将 `trimuse/main.py` 中的 `chief_path` 改为本卡。

- 几何: 二维轴对称随机五层 TRISO, 批次平均外半径 465 μm, 球形度 0.995, 随机种子 202609134, 展开最高次数 30。
- 功率: 整颗粒总发热功率 0.1 W, 全部由 kernel 产生; 包覆层不发热。该数值为测试设置, 不代表标定的反应堆工况。
- 热源: `external.power.constant` → `derived.volumetric_power.uniform` → 核心域热源积分。`Q=P/V_kernel`, 体积由有限元网格按二维轴对称约定计算, 不硬编码功率密度。
- 环境: 整个外表面 `environment_zone` 施加 Robin 边界, 环境温度 293.15 K (20 °C), 换热系数 500 W/(m²·K)。没有外加热通量。
- 初温: 所有材料均为 293.15 K, 与环境一致。温升仅来自核心内热源。
- 材料: 沿用已有 UO2、Buffer、PyC、SiC 配置和物性模型; 内界面理想接触, 不考虑辐射、间隙热阻和热膨胀。
- 网格: 二阶几何、H1 一阶温度场。目标尺寸为核心 30 μm、Buffer 20 μm、IPyC/OPyC 10 μm、SiC 8 μm; 尚未做网格收敛验证。

后向欧拉 (`theta=1`), 使用已有 Picard 配置更新温度相关物性。
