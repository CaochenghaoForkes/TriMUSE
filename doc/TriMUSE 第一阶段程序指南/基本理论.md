
# 强形式

导热方程

 $$c_v\frac{\partial T}{\partial t} -\nabla\cdot(k\nabla T)=Q \qquad \text{在 }\Omega\text{ 内}.$$

初始条件

$$T(\boldsymbol x,0)=T_0(\boldsymbol x).$$

三类边界

$$\begin{aligned}
T&=\bar T &&\text{在 }\Gamma_D,\\
-k\nabla T\cdot\boldsymbol n&=\bar q_{\mathrm{out}}
&&\text{在 }\Gamma_N,\\
-k\nabla T\cdot\boldsymbol n&=h_{\mathrm{ext}}(T-T_\infty)
&&\text{在 }\Gamma_R.
\end{aligned}$$

# 弱形式

取测试函数(温度的一种允许的虚变化) $v$，因为第一类边界上的温度已被指定，所以要求

$$v=0\qquad\text{在 }\Gamma_D.$$

强形式乘以 $v$，在域内积分：

$$\int_\Omega c_v v\frac{\partial T}{\partial t}\,\mathrm d\Omega
-\int_\Omega v\nabla\cdot(k\nabla T)\,\mathrm d\Omega
=\int_\Omega vQ\,\mathrm d\Omega.
$$
对第二项使用分部积分和散度定理

$$-\int_\Omega v\nabla\cdot(k\nabla T)\,\mathrm d\Omega
=
\int_\Omega k\nabla v\cdot\nabla T\,\mathrm d\Omega
-\int_{\partial\Omega}v\,k\nabla T\cdot\boldsymbol n\,\mathrm d\Gamma.$$

定义外表面的热流为 $q_{out}$ 根据傅立叶定理 $q_{\mathrm{out}}=-k\nabla T\cdot\boldsymbol n$ 整理得

$$\int_\Omega c_v v\frac{\partial T}{\partial t}\,\mathrm d\Omega
+\int_\Omega k\nabla v\cdot\nabla T\,\mathrm d\Omega
=
\int_\Omega vQ\,\mathrm d\Omega
-\int_{\partial\Omega}v q_{\mathrm{out}}\,\mathrm d\Gamma.$$

带入外边界条件 得到弱形式

$$\boxed{
\begin{aligned}
&\int_\Omega c_v v\frac{\partial T}{\partial t}\,\mathrm d\Omega
+\int_\Omega k\nabla v\cdot\nabla T\,\mathrm d\Omega
+\int_{\Gamma_R}h_{\mathrm{ext}}vT\,\mathrm d\Gamma\\
&\quad=
\int_\Omega vQ\,\mathrm d\Omega
-\int_{\Gamma_N}v\bar q_{\mathrm{out}}\,\mathrm d\Gamma
+\int_{\Gamma_R}h_{\mathrm{ext}}vT_\infty\,\mathrm d\Gamma.
\end{aligned}
}$$

# 形函数与局部自由度

单元内的近似温度写成

$$\boxed{
T_h|_{\Omega_e}
=\sum_{j=1}^{n_e}N_j^e(\boldsymbol x)t_j^e.
