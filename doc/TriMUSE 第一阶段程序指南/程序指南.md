
# 程序介绍

TRISO 颗粒多物理耦合燃料性能分析平台: TriMUSE (TRISO Multiphysics Simulation Environment) 

```TriMUSE
TriMUSE/
├── trimuse/          # Python 输入、几何网格、流程调度和后处理
├── cpp/              # C++ 有限元计算内核
├── bindings/         # Python 与 C++ 的接口
├── cases/            # 算例输入文件、对比脚本及计算结果
├── doc/              # 程序指南和说明文档
├── build/            # CMake 生成的构建目录及编译产物
├── CMakeLists.txt    # 项目构建入口
└── README.md         # 项目说明、环境配置和运行方法
```

**python 部分**
```trimuse
trimuse/
├── geometry/       # 几何构建、区域与边界划分、网格生成与优化
├── input/          # XML 输入读取、模板生成、单位换算与配置检查
├── postprocess/    # 结果读取、点线截面采样、云图与动画
├── __init__.py     # Python 包初始化
├── coupling.py     # 分阶段时间推进、属性更新与各物理场求解调度
├── fem.py          # 配置求积规则、有限元空间与连续／分区域场
├── main.py         # 程序入口，组织完整运行流程
├── output.py       # 输出目录、输入快照、运行报告与结果保存管理
├── problem.py      # 整理热与放射性问题配置，创建并调用 C++ 问题对象
├── properties.py   # 配置属性模型、材料分配及属性更新调用
└── solver.py       # 配置线性求解器、预条件器与非线性迭代参数
```

**cpp 部分**
```
cpp/
├── common/          通用数据类型、模型注册器、插值等基础工具
├── fem/             读取网格，管理连续场与分域场、有限元空间、自由度和求积点
├── output/          保存温度、浓度等场的 ParaView 结果及求解统计信息
├── physics/         组装和求解具体物理问题、装配、试探场和自由度约束代码
├── properties/      管理外部量、派生量和材料属性，按依赖关系更新属性值
├── solver/          管理求解器配置，执行线性求解与预条件处理
└── CMakeLists.txt    配置 C++ 源文件、MFEM 等依赖及编译目标
```

对于程序要求的基本物理量输入，支持单位转化 value : unit，程序内统一使用 si
```xml
	<outer_radius value="250" unit="[um]"/>
	<absolute_tolerance value="1e6" unit="[atom]/[m]^3" />
	<absolute_tolerance value="1e-6" unit="[K]" />
	<theta value="90.0" unit="[degree]" />
```

对于某个具体的属性，或物理过程，输入指定其具体模型名称以及这个模型计算需要涉及的多个参数，包括这些参数的输入单位和 SI 转化后的单位
```xml
	<nuclide_diffusion_coef model="common.arrhenius">
		<parameter name="D0" value="5.6" unit="[m]^2/[s]" si_unit="[m]^2/[s]"/>
		<parameter name="Q" value="209000" unit="[J]/[mol]" si_unit="[J]/[mol]"/>
	</nuclide_diffusion_coef>
```

# 几何与网格模块

```
trimuse/geometry/
├── __init__.py                       # 几何包初始化
├── builder.py                        # 统一调度几何构建与网格生成，复用已有网格
├── flat_multilayer_particle.py       # 构建带平面截断和圆角的多层颗粒几何
├── gmsh_mesh.py                      # 设置网格尺寸、阶次和优化方法，生成并保存网格
├── ideal_multilayer_sphere.py        # 构建理想同心多层球几何
├── stochastic_multilayer_particle.py # 根据统计参数构建随机多层颗粒几何
├── topology.py                       # 保存区域、边界与 Gmsh 几何实体的对应关系
└── zones.py                          # 按角度范围划分三维颗粒外表面边界
```

TriMUSE 使用 Gmsh 的 Python API 完成几何与网格生成：
* 几何构建：使用 Gmsh 集成的 OpenCASCADE 几何内核
	OpenCASCADE（OCC）：起源于 20 世纪 90 年代的工业 CAD 几何内核，后来以开源形式发布。它是一个 C++ 几何建模库，广泛用于三维 CAD 软件的曲面、实体建模和几何数据交换
* 网格生成：使用 Gmsh 的网格模块
	Gmsh：由 Christophe Geuzaine 和 Jean-François Remacle 开发的开源有限元网格生成软件，面向科研与工程计算，同时提供几何建模、网格划分和结果查看功能
